## Kontrol edilecekler

### 1. Token kayıt kontrolü

Login ve Google login sonrası JWT token nerede saklanıyor kontrol et.

AsyncStorage içinde token şu şekilde tutulmalı:

```ts
await AsyncStorage.setItem("token", token);
```

veya proje hangi key’i kullanıyorsa chat de aynı key’i kullanmalı.

Farklı key kullanımı varsa düzelt:

* authToken
* access_token
* token
* jwt

Hepsi tek standarda bağlansın.

### 2. API client Authorization header

frontend/src/api.ts içinde tüm protected endpointlere token otomatik eklensin.

React Native / Expo için AsyncStorage’dan token okunmalı ve header’a eklenmeli:

```ts
import AsyncStorage from "@react-native-async-storage/async-storage";
import axios from "axios";

api.interceptors.request.use(async (config) => {
  const token = await AsyncStorage.getItem("token");

  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }

  return config;
});
```

Eğer projede zaten interceptor varsa bozmadan düzelt.

### 3. Chat endpoint uyuşmazlığını kontrol et

Frontend hangi endpoint’e istek atıyor?

Şu an logda:
POST /api/chat/message

Backend gerçekten bu endpoint’i mi bekliyor?

server.py içinde mevcut chat endpointlerini bul:

* /api/chat/send
* /api/chat/message
* /api/chat/messages

Frontend ve backend aynı endpoint’i kullanmalı.

Tek standarda indir:
Frontend hangi endpoint çalışıyorsa onu kullansın.
Backend endpoint protected ise token zorunlu gelsin.
